# LuxuryBid starter website

This is a mobile-friendly **front-end design preview** for an original Ethiopian lowest-unique-bid marketplace concept.

## What works in this preview
- Responsive homepage layout
- Demo product cards
- Category filters and search
- Demo item detail modal
- Save/unsave heart buttons (visual only)

## What does NOT work yet
- Real user registration/login
- Real bids or server-side winner calculation
- Auction timers or live auction state
- Admin dashboard and product database
- Telebirr payments or payment verification
- Email notifications, delivery, refunds, identity checks

The banner and dialogs clearly identify the site as a demo. Do not accept real money or invite public bidding using this static preview.

## View it
Open `index.html` in a browser. For a public website, upload these files to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. A static host is enough for the preview, but the real auction system needs a backend and database.

## Recommended next steps
1. Choose the final brand name and domain.
2. Decide the auction rules: entry fee, permitted bid range, attempts per user, closing time, tie handling, and winner payment deadline.
3. Build a backend and database with server-controlled bids and auditable results.
4. Apply for Telebirr merchant/developer access and integrate the official payment flow server-side.
5. Add admin controls, security protections, terms, privacy policy, support, and test the system before launch.
